Abstract

This paper presents ViFA-Council, a three-stage multi-agent framework that employs multiple large language models (LLMs) to tackle two culturally complex generative tasks: image outpainting and educational story generation based on traditional Vietnamese folk paintings.

Current single-model generative pipelines frequently struggle with stylistic hallucinations and cultural misrepresentations because they lack mechanisms for cross-model critique. ViFA-Council addresses this challenge by orchestrating collaboration among GPT-4o, Gemini 3.1 Pro, and Claude Sonnet 4.6. It enforces rigorous cultural constraints through structured agent deliberation. This deliberation is mediated by task-specific JSON schemas that effectively bridge natural language discussions with diffusion-based image synthesis using Banana Pro.

Experiments and a user study demonstrate that structured multi-agent deliberation is a promising direction for improving cultural fidelity and narrative coherence in culturally sensitive, low-resource artistic domains.

Method

A three-stage Council that drafts, cross-refines and adjudicates

Given a folk painting I and a user directive q, the Council produces one Chairman-selected JSON configuration J*. Every stage reads and writes the same task-specific schema, so cultural and stylistic constraints are tightened before any image is generated.

  1. Parallel drafting

    GPT-4o, Gemini 3.1 Pro and Claude Sonnet 4.6 each fill the schema from the same painting and directive, without seeing one another’s output. Calls run concurrently with exponential-backoff retries.

    3 independent drafts

  2. Cross-model refinement

    Every agent reviews and improves every draft, whoever wrote it: checking structural validity, improving cultural fidelity, and returning the same schema. A failed call falls back to the original draft, so no candidate is lost.

    up to 3 × 3 = 9 refined candidates

  3. Chairman adjudication

    A separate Gemini 3.1 Pro instance, isolated from the earlier stages, receives all drafts and refinements under alphabetical labels. It scores structural validity, logical coherence, cultural fidelity and whether refinement helped, then names one winner.

    1 selected configuration J*

Task 1

Folk-painting outpainting

We compare ViFA-Council against GPT-4o, Gemini 3.1 Pro and Claude Sonnet 4.6, each prompted with the identical Stage 1 instruction but without cross-refinement or Chairman adjudication, and rendered through the same image pipeline. Experiments use a curated collection of 257 paintings: 112 Đông Hồ, 74 Hàng Trống and 71 Kim Hoàng works.

  • GPT-4o

    Typographical content injection

    Modern Vietnamese text is written straight onto the canvas, such as “VƯỜN NHÀ BÌNH YÊN” and “BÉ VUI ĐÙA”.

  • Gemini 3.1 Pro

    Cultural hallucination

    Imperial swirling clouds, ornamental rock gardens and curved-roof pagodas replace naive rural aesthetics with generic East Asian tropes.

  • Claude Sonnet 4.6

    Textural and chromatic degradation

    Boundaries are structurally plausible, but the earthy palette is flattened and the fibrous texture of giấy điệp paper is lost.

  • Gemini 3.1 Pro, stories

    Structural format drift

    Comic panels morph into modern educational infographics with rigid typographic headers.

Task 2

Educational story generation

The same Council turns a single painting into a multi-panel comic for children: characters stay consistent with the source print, dialogue is written in Vietnamese, and the story carries the painting’s cultural lesson. The baseline is Gemini 3.1 Pro with the Stage 1 instruction alone.

User study

Blind ratings from 15 participants

Ten STEM students, three educators and two AI engineers rated anonymized results in randomized order on a five-point Likert scale. ViFA-Council receives the highest overall rating on both tasks, with the lowest variance. For stories, the largest gains are in dialogue quality (3.96 vs. 3.54) and narrative coherence (3.94 vs. 3.66).

Limitations

ViFA-Council is evaluated zero-shot, without fine-tuning on Vietnamese folk-art data, which may limit adaptation to subtle school-specific conventions. The user study measures perceived cultural relevance and does not include professional folk-art historians or artisans, so historical and iconographic authenticity still needs expert assessment. The framework depends on the underlying LLMs and image model, and its multiple parallel API calls cost more and take longer than single-model generation.
